Security · Transparency

  • Zero Data Collection: Executed 100% client-side in your browser. Passwords are never sent to or logged on any server.
  • Direct Gateway: HTTP requests target the official university captive portal (122.252.242.93).
  • Zero Admin Elevation: Runs with standard user privileges without modifying system-level OS files.
  • 100% Open Source: Complete source code for scripts, C# binaries, and webpage is public and inspectable.
